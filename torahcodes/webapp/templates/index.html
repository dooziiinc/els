Positive skip reads forward through the text, negative skip backward; skip = 1 is an ordinary (unskipped) occurrence. "Same grid panel" vicinity search requires a candidate word's entire ELS to fall within the displayed rows; "radius" only requires its starting cell to be nearby. Short candidate words (2-3 letters) will often match somewhere nearby by chance alone -- that's expected, not a bug. See the project README for the statistical significance tools (permutation testing) that let you check whether a result is more notable than chance predicts.
